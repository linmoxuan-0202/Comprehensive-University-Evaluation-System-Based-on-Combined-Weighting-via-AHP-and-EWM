使用说明：
本项目基于 Python 3.8+ 开发，须预先安装 numpy、pandas、matplotlib 及 openpyxl 依赖库。运行前，请将 QS 大学排名原始数据（Excel 格式，包含大学名称、国际学生比例、国际教师比例、师生比、每位教员引用率、学术声誉、雇主声誉七个字段）置于项目根目录，文件命名为“副本QS2026年国内大学排名数据（1）.xlsx”。执行主程序 main.py 后，系统提供三种权重计算模式：
层次分析法（AHP）支持用户通过两两比较构建判断矩阵以确定主观权重；
熵权法（EWM）依据数据离散程度自动计算客观权重；
主客观组合赋权法则通过组合系数 α（取值0~1）将二者融合——α 越大越偏主观，越小越偏客观，用户可根据实际需求在代码中灵活调整判断矩阵与 α 参数。程序运行后将输出“QS_2026_单权重重新排名结果.xlsx”与“QS_2026_混合权重组合权重排名结果.xlsx”两份排名结果文件。
此外，本系统还配套了 Web 交互界面，接入 DeepSeek 大语言模型，支持用户通过自然语言描述需求自动获取推荐权重，也可自主构建判断矩阵实现个性化排名，并支持查看各高校详细指标评分与综合排名。
