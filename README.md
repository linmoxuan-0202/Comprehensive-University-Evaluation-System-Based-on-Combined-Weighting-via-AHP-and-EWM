# 项目描述

这是上海交通大学附属中学闵行分校MS7课题学习小组制作的高校综合评价系统。

# 使用说明

下载基于层次分析法与熵权法组合赋权的高校综合评价系统.html，使用GPT-5.6 sol模型和Python生成，大语言模型调用deepSeek实现，通过设置deepSeek api即可使用。

#主要流程

1. 需求表达：用户可以将自己的偏好和要求通过正常的语言告诉DeepSeek大语言模型，模型会自动生成合适的权重分布。
2. AHP主观赋权：进行两两比较与一致性检验
3. 熵权客观赋权：依据高校样本差异计算
4.  组合赋权：LLM辅助确定$\alpha$及附加条件
5.  排名与解读：给出高校综合排名、趋势和优势学科
